# Obesity Prediction Using KNN Algorithm

## About the Project
This project focuses on predicting obesity levels using the K-Nearest Neighbors (KNN) machine learning algorithm. It analyzes individuals' physical characteristics, eating habits, and lifestyle factors to classify obesity levels.

The project is implemented using Python in Jupyter Notebook.

## Objectives
- Analyze the obesity dataset.
- Perform data preprocessing and cleaning.
- Conduct Exploratory Data Analysis (EDA).
- Apply categorical encoding and feature scaling.
- Implement the KNN classification algorithm.
- Evaluate model performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm Used
K-Nearest Neighbors (KNN) is a supervised machine learning algorithm used for classification. It predicts the class of a new data point based on the majority class of its nearest neighbors.

## Dataset
The dataset contains physical characteristics, eating habits, and lifestyle-related information.

Target Variable: NObeyesdad (Obesity Level)

## Workflow
1. Import required libraries.
2. Load the obesity dataset.
3. Explore and understand the data.
4. Perform data preprocessing.
5. Encode categorical variables.
6. Split the dataset into training and testing sets.
7. Apply feature scaling.
8. Train the KNN model.
9. Predict obesity levels.
10. Evaluate model performance.

## Model Evaluation
- Accuracy Score
- Confusion Matrix
- Classification Report
